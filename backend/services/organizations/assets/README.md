# Fuentes del PDF de compromisos

Liberation Sans Regular y Bold se distribuyen con el servicio para generar
PDFs sin dependencias de fuentes instaladas en el sistema ni de otro servicio.
Se reutilizan los mismos recursos tipográficos institucionales del servicio
Insights. La licencia se conserva en `LICENSE_LIBERATION`.

El despliegue de Organizations debe incluir esta carpeta junto con `src/`.

`logo-fge.png` es la misma copia institucional que usa Insights para los
reportes (de `frontend/public/Logo-FGE-SIN-FONDO.png`). El PDF de compromisos
replica el encabezado, colores y tablas del reporte consolidado.
