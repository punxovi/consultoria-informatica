# KAN-166: formulario de Programas

El formulario permite crear, editar y archivar Programas Institucionales con
líneas de acción, resultados esperados, referencias e imagen.

Después de la migración de arquitectura, las operaciones de Programa se envían
al API Gateway y al `programs-service`. La validación inmediata del formulario
permanece en `frontend/src/lib/validaciones/programas.ts`; el servicio repite las
validaciones antes de escribir y Supabase conserva las restricciones y RLS.

La imagen sigue usando el módulo transversal de archivos y Storage con sesión
del usuario. No se utiliza `service_role` en el navegador.

## Verificación vigente

```powershell
npm.cmd run test --workspace=frontend
npm.cmd run test --workspace=@fge/programs-service
npm.cmd run build:frontend
```

La prueba funcional requiere iniciar sesión con ADMIN, crear un programa,
recargar su detalle, editarlo, comprobar la imagen y finalmente archivarlo.
